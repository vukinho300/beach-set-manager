# Shared Architecture

Status: `prototype_decision`

Petalon is the first shared location. The future central database is authoritative, while realtime notifications keep connected clients current.

The first shared implementation slice is Beaches + Beds. Vuk and Vito must load the same state, see each other's accepted changes, and retain the same result after refresh.

Later migrate reservations, transactions, non-numbered Sunbeds and Aquapark. Important simultaneous edits must be checked centrally rather than silently overwriting each other.

Use a service/repository layer between React components and the backend so App.tsx does not become coupled to one persistence implementation.
